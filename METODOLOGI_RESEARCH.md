## 1. Pertanyaan Riset (RQ1, RQ2, RQ3)

Dirumuskan dari tesis dan 10 rencana riset final (C1-msg84–96, C2-msg5):

- **RQ1 (Ontologi–Epistemologi–Aksiologi):** Bagaimana Pancasila dapat direkonstruksi sebagai sistem filsafat yang koheren — manusia monodualis-monopluralis (ontologi), sintesis rasio–wahyu–budaya–musyawarah (epistemologi), keadilan sosial substantif (aksiologi) — dalam dialog dengan filsafat Barat (Plato, Aristoteles, Descartes, Kant, Heidegger, Rawls, Sen, Nussbaum, Fraser, Young), Timur (monodualisme, Konfusianisme, Advaita), dan hermeneutika (Gadamer, Ricoeur)?
- **RQ2 (Jalan tengah):** Apakah klaim Pancasila sebagai "jalan tengah" antara liberalisme dan komunisme kredibel bila diuji pada poros kebebasan, peran negara, HAM, demokrasi, ekonomi/kepemilikan, dan ketuhanan — dan syarat apa (konsistensi praktik negara, deliberasi-agonistik, demokratisasi tafsir) yang memenuhinya?
- **RQ3 (Relevansi kontemporer):** Bagaimana Pancasila sebagai ideologi terbuka berdialog resiprokal dengan nilai global, etika digital/tata kelola kecerdasan artifisial, kapitalisme platform/ekonomi kerakyatan, dan pendidikan karakter — di tengah paradoks generasi muda (ketahanan simbolik tinggi vs kerapuhan substantif: CSIS 2023, Litbang Kompas 2023, Semarang)?

Prompt operasionalnya (C1-msg49, ≤500 karakter, dipakai di LeapSpace): Prompt 1 filosofis; Prompt 2 vs liberalisme; Prompt 3 vs komunisme; Prompt 4 relevansi global-digital.

## 2. Formulasi Masalah

- **Gap-1:** Kajian parsial (politik / karakter / hukum terpisah); jarang mengintegrasikan ontologi–epistemologi–aksiologi dalam satu kerangka sistemik (C2-msg5).
- **Gap-2:** Perbandingan vs liberalisme/komunisme berhenti di slogan individualisme–kolektivisme, tanpa bedah poros rinci (C2-msg5).
- **Gap-3:** Kritik post-foundational (Kim: *empty signifier*; seruan *agonizing Pancasila*) belum dijawab filsafat hukum Indonesia (C2-msg5).
- **Gap-4:** Minim kerangka operasional-teknis untuk tata kelola algoritma, perlindungan data, kapitalisme platform, krisis ekologis (C2-msg5).
- **Tesis:** Pancasila = sistem filsafat koheren; jalan tengah kredibel dengan syarat deliberatif-substantif + konsistensi praktik; ideologi terbuka yang relevan (C2-msg5).

## 5. Praproses

Pipeline praproses korpus (C1-msg102–128):

1. **Ekstraksi URL** (`extract_all_urls.py`) dari daftar "Karya yang dikutip" laporan.
2. **Unduhan** (`download_all.py`: Session, header browser, rotasi Referer, timeout 90 dtk, 5× retry).
3. **Audit tipe file** (skrip PowerShell cek folder `referensi/`): PDF vs HTML; HTML dipilah — penting (jurnal SINTA/Scopus → konversi/cari PDF) vs abaikan (profil SINTA/dosen, modul, berita, login-page 3038-byte).
4. **Ekstraksi metadata** 30 dokumen pendukung dari halaman pertama tiap dokumen.
5. **Normalisasi sitasi** ke BibTeX; 7 inti verifikasi Crossref (Latif 2018, Madung 2016, Duha 2022, Kim 2024, Pristiwiyanto 2021, Madung & Mere 2021, Ulum & Hamida 2018); 33 DOI sisa sebagai `@misc` minimal → dilengkapi via SciSpace Citation Generator.

## 10. Ablation & Analisis

(TIDAK ada ablation study formal. Analisis sensitivitas yang dilakukan di chat:)

1. **Tanpa deliberasi** → demokrasi transaksional; **tanpa ontologi relasional** → teokrasi simbolik; **tanpa aksiologi** → populisme distributif — hanya sistem utuh yang bekerja (C2-msg5).
2. **Elsevier vs IEEE**: Elsevier 20 hlm tapi tabel rapuh/teks nyebrang → IEEE 12 hlm rapi; keputusan pindah template (C1-msg167–180).
3. **Cover code vs image**: programatik (TikZ) fleksibel tapi rapuh/berat → image stabil; pengguna memilih image (C5–C6).
4. **Retry unduhan**: header+Session+Referer+timeout hanya +1/31 → simpulan: hambatan bersifat akses (login/paywall), bukan teknis (C1-msg114).
5. **Revisi bertingkat**: OpenCode (isi) → Claude (substansi) → DeepSeek (format) — tiap lapis menemukan cacat yang lolos dari lapis sebelumnya (C1-msg139).

## 11. Reproducibility

- Skrip: `extract_all_urls.py`, `download_all.py`, `retry_failed.py` + skrip PowerShell audit (dapat dijalankan ulang; gunakan tanda kutip untuk path berspasi!).
- Prompt terdokumentasi: 4 LeapSpace, Elicit, SciSpace, Gemini gabungan, Claude (tulis/revisi/format), OpenCode (SciSpace, unduh, konversi IEEE).
- Toolchain: TeX Live 2026; `pdflatex → bibtex → pdflatex ×2`; file `.bib` acuan **perlu penetapan tunggal** (konflik fix vs final — lihat PRD Lampiran B).
- Batasan repro: hasil tools berpemilik (LeapSpace/Perplexity/Gemini/Claude) bergantung kuota & waktu akses; 30 sumber login-wall hanya repro manual.

## 12. Pipeline

```
Korpus (168) → praproses (ekstrak→unduh→audit→metadata→BibTeX)
  → analisis (PRISMA → tematik → komparasi → hermeneutika → uji berlapis)
  → validasi (Consensus/Scite/graph + verifikasi terprogram)
  → penulisan (Claude) → kompilasi (LaTeX) → typesetting IEEE → submit
```

Orkestrasi peran: pengguna (kontrol) → DeepSeek (operasional) → Claude (tulis/revisi) → OpenCode (eksekusi).
